# CloudGuard — Cloud Security & Governance Simulator

A lightweight academic project demonstrating IAM/least privilege, storage misconfiguration, audit logging, governance scoring and the Shared Responsibility Model.

## Run
Open `index.html` in a browser.

## GitHub Pages
Create a public GitHub repository, upload the three website files plus this README, then enable **Settings → Pages → Deploy from branch → main → /root**.

## Running example
1. Viewer + Delete → Test Access → DENIED.
2. Admin + Delete → Test Access → ALLOWED.
3. Show PUBLIC storage risk.
4. Apply Secure Policy → PRIVATE + score 100.
5. Explain how IAM, storage policy and audit logging support governance.

This is a security-control simulator, not a production cloud environment.
